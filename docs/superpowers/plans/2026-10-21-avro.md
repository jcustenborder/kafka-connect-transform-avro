# Raw Avro Transformation Implementation Plan

**Goal:** implement the approved raw Avro SMT with the XML project's build/release cycle.

**Architecture:** FromAvroConfig validates and loads one writer schema. FromAvro
decodes a datum and delegates Connect mapping to provided Confluent AvroData.

**Tech stack:** Java 17, Maven parent 4.3.1-2, Confluent converter 8.3.2, JUnit.

## Constraints

- No IDE-specific tooling. Use the existing isolated feature worktree.
- Mirror the XML project's PR and release workflow, using this repository's main default branch.
- Keep Kafka and the Confluent converter provided; use existing parent dependencies.
- Implement inline in this session; verify tests before committing and opening a PR.
